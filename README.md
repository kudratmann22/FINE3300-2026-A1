# FINE3300-2026-A1
## Description

This program is built to convert currency between USD and CAD. It works by reading the most recent exchange rate from the Bank of Canada CSV file and then asks the user for an amount they wish to convert and the currencies

## How to Run
To use this program, first run the command below in the Terminal (python3 ExchangeRates.py). Then the user will be prompted to enter the amount, then the currency to convert, and then the currency to convert to (in all caps, USD or CAD)
